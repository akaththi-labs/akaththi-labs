# Akaththi Labs

Source of the Akaththi Labs website. Akaththi Labs builds automation and
technology for living systems, starting with cultivation: the POD chamber,
Kaani Intelligence and managed farms. Based in Chennai, India.

## What this repository is

- The static website for Akaththi Labs, served by GitHub Pages.
- A place for future open-source tools, once there is something to release.
- Not the product. POD designs and the core of Kaani Intelligence are
  closed and are not stored here.

## Build the site

The pages are generated by a small script with no dependencies. Node 18 or
later is enough.

```bash
node _tools/build.mjs
```

The script writes the HTML files into the repository root. Commit the
generated files together with the source change.

| Path | What it holds |
|---|---|
| `_src/config.mjs` | Site settings: base path, canonical URL, enquiry address |
| `_src/layout.mjs` | Shared header, footer and page shell |
| `_src/pages.mjs` | The copy for every page |
| `_tools/build.mjs` | The build script |
| `assets/css/site.css` | The whole stylesheet |
| `assets/fonts/` | Self-hosted fonts and their licences |
| `assets/brand/` | Logo files for web, print and social. See its README |
| `_tools/make-brand.mjs` | Regenerates every logo size (optional, needs Playwright) |

Folders that start with an underscore are not published by GitHub Pages.

## GitHub Pages

Static files at the repository root, so no build runs on GitHub.

1. Settings, Pages.
2. Source: Deploy from a branch.
3. Branch `main`, folder `/ (root)`. Save.

The site then appears at `https://akaththi-labs.github.io/akaththi-labs/`.
`.nojekyll` tells Pages to serve the files exactly as they are.

## Logo

The mark is a square frame with a square seed breaking the corner. Every
size for web, apps and social is in `assets/brand/`, with a README that
lists where each file goes.

## Settings to review

- **Enquiry address.** `contactEmail` in `_src/config.mjs` is empty, so the
  enquiry button opens a public GitHub issue. Set a monitored address to
  switch to email.
- **Base path.** `base` and `url` assume the project address
  `akaththi-labs.github.io/akaththi-labs`. Change both if the site moves to
  a custom domain.

## Writing rules for the site copy

- Say what exists, what is in build and what is planned. Use the status
  words `building`, `in design` and `planned`.
- No performance figures, customer names or yield claims until they are
  measured and approved.
- No design details of the POD or its cooling system. Those are protected.
