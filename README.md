# Akaththi Labs

> Open-source research and development for embedded systems and beyond

Akaththi Labs is the open-source research arm of Akaththi Farms, focused on building robust, production-grade libraries and tools for embedded systems, sensors, and IoT infrastructure.

## Mission

We develop and maintain open-source software that solves real-world problems in agriculture, environmental monitoring, and industrial automation. Our work is driven by practical needs and shared freely with the community.

## What Akaththi Labs Is

- **Open source first**: All projects are open source under permissive licenses
- **Production focused**: Code designed for real-world deployment and reliability
- **Community driven**: Built with and for the embedded systems community
- **Research backed**: Grounded in practical research and field testing

## What Akaththi Labs Is Not

- **Not a SaaS platform**: We build libraries and tools, not hosted services
- **Not a commercial product**: No paid tiers, subscriptions, or premium features
- **Not vaporware**: We ship working code for real problems we've encountered

## Domains

### Active

#### Embedded Systems
Our primary focus is on embedded firmware and sensor libraries for resource-constrained environments.

**Technologies:**
- ESP-IDF (Espressif IoT Development Framework)
- FreeRTOS
- Sensor integration and calibration
- Low-power wireless protocols

### Planned

Future research domains include:
- **Edge Computing**: ML inference on embedded devices
- **Networking**: Mesh networking and LoRa protocols
- **Data Infrastructure**: Time-series databases for sensor data
- **Agricultural Tech**: Precision farming tools and analytics

## Projects

### ESP-IDF Sensor Libraries

Our current focus is developing high-quality sensor drivers and libraries for the ESP-IDF platform.

**Active Projects:**
- Sensor abstraction layers for I2C/SPI devices
- Calibration and filtering utilities
- Power-efficient sensor polling strategies
- Field-tested environmental sensor drivers

> **Note**: Individual project repositories will be created as components mature and are ready for public release.

## Contributing

We welcome contributions from the community. All projects follow standard open-source contribution practices.

### How to Contribute

1. **Find a project**: Browse our repositories or check project issues
2. **Discuss first**: For major changes, open an issue to discuss your approach
3. **Fork and branch**: Create a feature branch from the main branch
4. **Write tests**: Include tests for new functionality
5. **Submit a PR**: Open a pull request with a clear description of changes
6. **Code review**: Maintainers will review and provide feedback

### Contribution Guidelines

- Follow the coding style of the project
- Write clear commit messages
- Add documentation for new features
- Ensure all tests pass before submitting
- Keep changes focused and atomic

### Code of Conduct

We are committed to providing a welcoming and inclusive environment. Be respectful, considerate, and professional in all interactions.
